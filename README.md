# 🥮 月白之隱：中秋烤肉大作戰 (Moon BBQ Panic)

一款以「中秋節烤肉狂歡」為主題的 Overcooked 風格 2D 俯視角協作烹飪 H5 遊戲。玩家扮演月宮大廚，在時限內拿取食材、切備料、烤肉、裝盤出餐與洗碗，爭奪排行榜寶座！

---

## 🎮 遊戲特色
- **經典烹飪循環**：食材拿取 $\rightarrow$ 切菜備料 $\rightarrow$ 炭火烘烤 $\rightarrow$ 裝盤出餐 $\rightarrow$ 髒盤洗滌。
- **炭火火候系統**：掌握食材生熟狀態，避免烤焦釀成廚房危機。
- **單人 / 雙人本地合作**：支援鍵盤雙人對戰/合作與手機觸控操作。
- **會員與排行榜**：支援註冊登入、個人戰績保存與全局排行榜。
- **純粹輕量與高相容**：全自製 Web Audio 擬真音效與 Canvas 粒子特效，零肥大依賴。

---

## 🚀 本地執行方式 (Local Setup)

```bash
# 1. 安裝依賴套件
npm install

# 2. 啟動本機開發伺服器
npm run dev

# 3. 建置生產版本
npm run build
```
